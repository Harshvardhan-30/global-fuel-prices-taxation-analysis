# Global Fuel Prices and Taxation Trends

### A Comprehensive Global Performance Intelligence Report

## 1. Project Overview

This project analyses global fuel prices, taxation, subsidies, and economic development trends using Tableau Public. It explores how petrol, diesel, and LPG prices vary across countries and regions, and how taxation, subsidies, and crude oil prices relate to these variations.

The project transforms a global fuel-price dataset into interactive dashboards designed to support data exploration, policy analysis, and supply-chain planning.

## 2. Project Objectives

- Analyse global petrol, diesel, and LPG price variations.
- Explore the relationship between fuel prices and taxation.
- Examine the role of fuel subsidies in different countries.
- Compare fuel-price trends across geographical regions and income levels.
- Explore how crude oil prices relate to retail fuel prices.
- Present insights through interactive Tableau dashboards.

## 3. Tools and Technologies

- **Tableau Public:** Data visualisation, dashboard development, and interactive analysis.
- **CSV Dataset:** Source data for the analysis.
- **GitHub:** Project documentation, dataset organisation, and version-controlled project files.

## 4. Dataset Overview

The dataset contains approximately 27,468 records covering 84 countries and 7 geographical regions, from January 2020 to April 2026.

Key fields include:

- Date
- Country
- Region
- Income Level
- Subsidy Level
- Petrol Price (USD/litre)
- Diesel Price (USD/litre)
- LPG Price (USD/litre)
- Brent Crude Oil Price
- Tax Percentage

The dataset is provided in the `data/` directory.

## 5. Interactive Dashboards

The Tableau workbook contains three analytical dashboards and a supporting worksheet.

### Dashboard 1: Fuel Taxation and Subsidy Policy

Explores fuel taxation, subsidy policies, and differences in fuel prices across countries.

### Dashboard 2: Global Fuel Prices and Supply Chain Planning

Examines fuel-price variations and trends to support supply-chain planning and comparative analysis.

### Dashboard 3: Fuel Prices, Taxation and Economic Development

Explores relationships between fuel prices, taxation, and country-level economic categories.

### Supporting Worksheet

**Global Petrol Price Trend** supports the analysis of petrol-price movements over time.

## 8. Project Limitations

- The analysis is based on the supplied dataset and its available fields.
- Findings represent patterns and relationships in the data; they do not independently establish causation.
- The project uses Tableau Public and a CSV dataset. A separate automated ETL pipeline, live data feed, or database backend is not part of the documented implementation.
